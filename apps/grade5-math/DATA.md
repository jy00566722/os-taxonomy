# 匿名数据与“重新开始”

当前没有账号注册、登录、孩子档案或跨设备同步。浏览器的 `math_profile` Cookie 是一个随机匿名标识。

所有记录物理存放在服务器 `/var/lib/grade5-math/math.db` 这一个 SQLite 数据库中；WAL 模式还可能有同目录 `math.db-wal` 和 `math.db-shm`。同库不等于同一份答题：sessions 表有 owner，读写都同时按会话 ID 与 owner 限定。

- 不同浏览器档案/设备通常有不同 Cookie，看到各自的记录。
- 同一个浏览器中多个孩子共用页面，会共用匿名身份；当前不能区分他们。
- “新体检”新建 session，保留旧 session；题目和判分证据在会话快照中保存。
- 暂停、刷新、重启应用可以继续当前记录。
- 目前没有“清空本设备历史”、删除历史 API、自动过期清理或管理员重置界面。
- 删除 Cookie 或使用无痕窗口得到新匿名身份，旧记录不会被删除，也不会自动找回。

本次只说明现状，没有擅自增加账号或重置功能，也没有清空任何已有记录。后续若需要重置，应先明确是重做一次测验、切换孩子，还是永久删除历史，不能混为同一个操作。
