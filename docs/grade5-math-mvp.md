# 五年级数学小体检：首版开发方案

状态：首版本地原型已实现；分支 `codexY/grade5-math-check`。源码与启动方式见 `apps/grade5-math/README.md`。六模块、12 个能力点、72 道题已接入；教学内容仍待教师审阅与实际学生验证。

## 1. 产品目标

让五年级学生用一次短测发现值得继续确认的知识点，看到相关基础知识，完成少量针对性练习，再用新题复测。

完整路径：**选择已学内容 → 短测 → 查看学习线索 → 练一练 → 换题复测 → 保存本次进展**。

首版以中文、单个孩子在同一浏览器使用为场景。界面清爽、鼓励探索，题目一次显示一道，平板与电脑均可操作。时间仅为提示，不强制倒计时。

成功标准是孩子能理解“接下来练什么、为什么练”，而不是获得一个缺乏依据的综合能力分数。

## 2. 内容范围与课程边界

用户已确认覆盖五年级数学各模块，先完成小闭环。第一批每模块选两个能力点，共约 12 个目标能力点：

| 模块 | 首批候选能力点 | 可追溯的基础 |
| --- | --- | --- |
| 小数与运算 | 小数位值及比较；小数乘除中的数量关系 | 整数位值、乘除意义 |
| 分数与数感 | 等值分数；分数大小比较 | 单位整体、分数意义 |
| 因数与倍数 | 因数与倍数识别；公因数与公倍数 | 乘法关系、整除 |
| 式与方程 | 用字母表示关系；简单等式求未知数 | 运算关系、等式意义 |
| 图形与测量 | 面积关系；体积与单位 | 长方形面积、单位与计量 |
| 统计与可能性 | 读取图表并比较；判断简单事件可能性 | 数量比较、分类 |

以上是产品的候选分组，不宣称已对齐中国某版五年级教材或学期。现有数据来自国外课程体系，年龄重叠不能证明适合中国五年级。

应用允许选择已学模块，并在每题提供“还没学过”和“暂时不会”：前者记为未覆盖，后者仅作为追问线索，均不得直接记为知识薄弱。应用题作为能力点的情境题出现。

内容单独维护中文 `skills` 和原创 `questions`，关联原仓库的稳定 topic ID。关联需要人工核对含义、范围和前置关系；映射可以是一对多。不改原始 `data/`、`schema/` 和原数据 manifest。

每个目标能力点先准备至少 6 道经人工核对的题目，区分筛查、确认、练习和复测用途。首批约 72 道；同一会话内不重复题目。复测题需要改变数值或表达方式，不能仅打乱选项。前置知识若没有题目，只展示关系并标注“未检测”。

## 3. 页面与体验

1. **开始页**：一句话说明用途、选择已学模块、开始或继续上次短测。不要求注册、真实姓名或生日。
2. **做题页**：一道题、清楚的输入区、提交、进度，以及未学过/暂时不会选项。数字、分数显示清晰，大按钮可触控。
3. **结果页**：列出本次检查内容、需要再确认的点、未检测内容；优先推荐一个下一步，不展示排名。
4. **知识路线**：只显示当前能力点、直接前置知识和下一步，通常 3–5 个节点；节点区分“本次已检测”和“关系参考”。
5. **练习与复测**：练习提供解释和提示；复测使用新题，单独记录结果。结束后回到结果页。

视觉方向：暖白底、深色文字、一种主色；少量完成反馈，不使用密集仪表盘、强制音效、排行榜、连续打卡惩罚或复杂 3D 图。

## 4. 短测与诊断规则

首轮从每个已选模块抽一道筛查题，全部模块约 6 题；根据答题情况追加最多 4 道确认题。一次短测最多 10 题。模块内轮换能力点，并明确列出本次没有检查的点。

这是小范围筛查，不据此声称完成全部五年级知识诊断。

规则保持可解释：

- 单题答对：显示“这题完成了”，保留样本不足状态。
- 单题答错：显示“还需要确认”，追加不同题型或基础题；不能直接判定薄弱。
- 同一能力点两道独立题均正确：显示“本次初步顺畅”，不能升级为长期掌握。
- 同一能力点两道独立题均错误：推荐巩固；如果基础题没有检测，不推断错误一定来自前置知识。
- 一对一错、跳过、未学过或确认题用尽：保留“不确定/未检测”等真实状态。
- 能力点诊断按各自证据计算，模块仅汇总这些结果，不把一个点外推为整个模块。
- 作答用时保留为体验信息，不作为“不会”或能力高低的依据。

知识图谱仅用于解释关系和选择有题目支持的追问候选。`hard` 边优先作为候选，`soft` 边作为参考；不把所有前置节点设为强制关卡。

练习每轮约 2 道，提供解释与适当提示。随后安排 2 道未见过的复测题：两题均正确则显示“本次复测通过”，否则继续标注需要巩固。使用过提示的练习不计入独立检测证据。跨天保持程度需要后续新题验证，首版不显示“已永久掌握”。

## 5. 技术方案

- **后端：Go**，先使用标准库 HTTP 路由与 JSON API。当前本机 Go 为 1.24.3。
- **前端：Vue 3 + TypeScript + Vite**，使用普通 CSS 和少量 SVG 实现知识路线，不引入完整图可视化框架或大型组件库。
- **存储：SQLite**，保存匿名浏览器档案、会话和答题记录；内容以版本化 JSON 维护。具体驱动在脚手架阶段确定并锁定版本。
- **运行：**开发时 Vite 代理 `/api`；构建后由 Go 提供静态文件和 API，同源运行。使用单个 SQLite 文件，首版无需 Docker 或外部服务。
- **判分：**服务端完成；数值题用十进制或有理数精确比较，避免直接用浮点数比较。分数支持等值形式；题目若考查“最简分数”，另设化简规则。
- **题型：**首版支持单选、数字输入、分数输入；几何题可附静态 SVG。不依赖手写识别、拍照或模型判分。
- **AI：**运行时不依赖模型或 API Key；后续即便辅助编题，也必须经内容审核后进入固定题库。

建议目录：

```text
apps/grade5-math/
  README.md
  content/
    skills.json
    questions.json
    taxonomy-map.json
  backend/
    cmd/server/
    internal/content/
    internal/assessment/
    internal/storage/
    internal/httpapi/
    go.mod
  frontend/
    src/
    package.json
```

应用使用的少量图节点和关系由检查脚本从原数据投影生成，并记录来源版本/哈希；生成脚本需要提交，不能依赖未公开的 `exportTaxonomy.mjs`。服务启动时校验题目、能力点映射、引用和图无环性。

## 6. 数据与接口约定

核心数据：

- `Skill`：中文名称、模块、目标/基础角色、相关 topic IDs。
- `Question`：稳定 ID、版本、能力点、用途、题型、题干、选项、答案规则、解析；每题指定一个主检测点。
- `Session`：匿名档案、模式、题库版本、选定模块、题序、当前进度、完成状态。
- `Response`：会话题目、原始回答、判分、跳过原因、是否使用提示和服务端时间。
- `SkillEvidence`：从独立作答记录推导的观察结果，附样本数、题目来源与观察时间。

最小 API：

```text
GET  /api/modules
POST /api/sessions
GET  /api/sessions/{id}
POST /api/sessions/{id}/answers
GET  /api/sessions/{id}/result
GET  /api/skills/{id}/route
POST /api/sessions/{id}/follow-up
```

会话中的当前题不包含答案和解析；筛查模式提交后保存作答，确认阶段结束再反馈诊断。练习提交后可以返回解释。结果只根据服务端保存的证据生成。

用随机匿名 Cookie 绑定本地浏览器档案，会话访问必须归属该档案。提交用唯一会话题目 ID 去重；重复点击或重试返回原结果，不产生双份证据。刷新后恢复当前位置。会话绑定题目快照或不可变内容版本，避免更新题库导致历史作答被重新解释。

## 7. 开发顺序与验收

1. **基础骨架**：Go 服务、SQLite、Vue 页面、内容加载与校验，提供一条明确的本地启动命令。
2. **小数模块纵向闭环**：筛查、确认、结果、路线、练习、复测、刷新恢复全部打通。
3. **扩展六模块**：补齐首批能力点与审核后的题目，复用已有流程；六模块均能完成闭环才算首版完成。
4. **验收**：实际浏览器走完整流程，再验证平板尺寸、内容与诊断边界。

必要检查：

- 原仓库 `npm test` 和 `npm run validate` 继续通过。
- Go 测试覆盖精确判分、等值分数、跳过、证据不足、追问上限、复测和重复提交。
- 内容检查覆盖唯一 ID、题目引用、用途库存、选项与答案一致性、映射和图循环。
- 浏览器验收覆盖正确、错误、未学过、刷新继续、断网重试、练习及复测路径。
- 题目和解析经人工复算；静态结构校验不能代替教学内容审核。
- 界面准确展示本次覆盖范围和证据，不输出未经验证的掌握率或排名。

首版完成后，再根据实际使用决定是否增加教材/学期映射、多个孩子档案、跨设备同步或长期复习。
